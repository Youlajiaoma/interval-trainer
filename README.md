# Tonaloom

**练耳 · 识谱 · 进步看得见**

一款面向日常练耳与基础识谱的轻量练习工具。打开网页即可使用，也可以添加到手机桌面，像普通应用一样启动。无需注册账号。

**[打开 Tonaloom，开始练习](https://youlajiaoma.github.io/interval-trainer/)**

## 两类练习 · 四个模块

### 和声音程

同时播放两个钢琴音，判断它们之间的音程。从纯一度到纯八度，共有 13 种音程可选。可以自由选择练习范围、音区和播放时长；答题后可使用「分开听」依次聆听两个音。

### 旋律音程

先后播放两个音，辨认音程及其走向。采用钢琴、吉他、长笛、萨克斯等乐器的预录音源，上行、下行分别记录掌握情况，并参与错题复习。

### 音符辨认

每组 20 个音符，以三行五线谱展示，结合不同节奏型练习认音。支持高音谱号、低音谱号或混合出题，也可以选择是否包含升降号。

使用带黑键的钢琴键盘作答，**不要求判断八度**：当前音符显示绿色，答错短暂闪红、留在原题重答；答对后，播放谱面对应实际音高的钢琴声，音符恢复黑色并移至下一题。

### 音程辨认

每组同时显示 10 道谱面和声音程：上方高音谱号 5 题、下方低音谱号 5 题，每题的两个音符上下叠放为和弦。逐题识别并选择答案。沿用和声音程的 13 种答案选项及排列方式；正确后自动进入下一题，支持独立的统计与间隔复习，每组 10 题，固定使用高低音两种谱号。答错可继续尝试，**答对后同时播放两个音符的钢琴和声**，也可以显示答案或开启下一组。

## 错题复习与统计

- 根据作答情况自动增加易错内容的练习机会，并安排间隔复习。
- 和声音程、旋律音程及识谱分别保存学习情况；识谱还区分不同谱号和音符位置。
- 可以查看正确率、答题记录、易混淆内容及最近的练习表现。

## 在手机上使用

1. 打开 **[Tonaloom](https://youlajiaoma.github.io/interval-trainer/)**。
2. 在首页选择想练习的模块。
3. 通过练习界面右上角的齿轮调整设置；在首页进入统计页面查看学习记录。
4. 如需桌面图标，可使用浏览器的「添加到主屏幕」或「安装应用」。

首次打开请保持联网，等待需要的资源加载；完成缓存后可在离线条件下使用已缓存的练习内容。出现「发现新版本」时，可以直接在应用内更新。

## 学习记录与备份

学习记录存储在**当前设备、当前浏览器**中，不会自动同步到其他设备。进入「练习统计 → 数据备份与管理」，可以导出 JSON 文件或导入旧备份。**导入会覆盖现有记录**，更换手机、卸载应用或清除浏览器数据前，建议先导出备份。
