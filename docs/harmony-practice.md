# 和声练唱音频接入

首页「练耳 → 和声练唱 → 在他乡」中只显示「旋律+和声、伴奏」两个项目。旋律、和声两份 WAV 作为混合素材保留，通过平衡条两端即可单独聆听，不再显示两个独立入口。「旋律+和声」使用这两份原音轨同步播放，不再需要或保存 `melody-harmony.wav`。「伴奏」尚未提供，保留「音频待添加」状态。

文件放在 `site/assets/harmony-practice/zai-ta-xiang/`，再修改 `site/assets/harmony-songs.js`。`stems` 保存混合素材路径，`tracks` 只列出目录里要显示的项目，例如：

```js
{
  id:'zai-ta-xiang', title:'在他乡',
  stems:{
    melody:'assets/harmony-practice/zai-ta-xiang/melody.wav',
    harmony:'assets/harmony-practice/zai-ta-xiang/harmony.wav'
  },
  tracks:[
    {id:'melody-harmony', title:'旋律+和声', mix:['melody','harmony']},
    {id:'accompaniment', title:'伴奏', src:null}
  ]
}
```

`mix` 中填写同一首歌 `stems` 里的两个素材名，顺序为旋律、和声；兼容旧清单中引用独立音轨 `id` 的写法。伴奏可使用 `accompaniment.wav`，文件扩展名必须和实际文件相同。`src` 使用上述网页相对路径和正斜杠 `/`，不能填写 `D:\...` 或 `file:///...` 电脑磁盘路径。原文件保留，播放器不改音高、速度；混合页只调节两轨的输出音量。这里接入项目文件，不提供账号或服务器上传服务。

平衡范围为 −100～100：0 对应旋律/和声增益 1/1；负值保持和声为 1，旋律为 `(100 + 值) / 100`；正值保持旋律为 1，和声为 `(100 − 值) / 100`。向左（旋律端）减少旋律，向右（和声端）减少和声；两端为 0/1 和 1/0。拖动不重新加载或改变播放位置；单轨页面不显示此控件。

平衡条前的 M 按钮点亮后，同时静音旋律和和声，进度继续前进。静音时调整平衡仍然无声；取消 M 后恢复新的平衡值，不重播或跳转。静音只作用于混合项目，伴奏等普通单轨不受这个开关影响。

拖动进度时先暂停并临时静音，连续拖动不播放任何位置片段。指针松开或键盘按键释放后，等最后一次跳转结束再按原状态继续；原来暂停则保持暂停，M 已开启则保持静音。临时静音不点亮 M。切换音轨或离开时取消等待，迟到的跳转事件不会恢复声音。

歌曲清单联网时优先获取最新内容，离线时使用最近缓存的清单。首次更新旧网页后，可从本地预览的新地址打开并刷新；不需要清除练习记录或重新安装 PWA。仅修改本地文件不会同步到已发布网站。

新增歌曲时，在同一清单中追加一个有独立 `id`、`title` 和 `tracks` 的项目即可，目录自动生成。目录名称使用文本节点，音频通过相对路径引用。音频及其相关许可需由提供者确认。

顺序播放从选中音轨继续到最后一项后停止，不跳过未添加的项目，也不自动回到第一项。循环播放使用原生 `audio.loop`，重复当前音轨。切换模式保留当前音轨和进度。播放器支持暂停、继续、上一音轨、下一音轨及进度拖动；返回音轨目录立即停止并释放音源，逐级返回歌曲目录和首页。

所有项目复用同一个原生 HTML `audio` 播放器，以保留手机的播放许可。混合页先解码两份音频，在浏览器内存中把它们存入互相独立的声道，共用一个原生媒体时钟，再用 Web Audio 分别控制两轨增益，并把每轨正常输出到左右声道。这样暂停、跳转和原生循环由同一时间轴控制，避免两个独立播放器发生起播偏差。切到单轨后原音频直接输出，绕过混合增益。临时传输数据不预先叠加波形、不上传、不写入仓库；原来的合成音频已删除。单声道输入保持单声道幅度，立体声输入保留每轨左右声道，时长较短的音轨末尾补零；临时资源在退出模块时释放。

切后台或锁屏时不主动暂停。支持时接入 Media Session 的锁屏播放/暂停、上下音轨及进度控制，并在播放期间请求 `audioSession.type = 'playback'`，离开后恢复。实际后台播放、Web Audio 处理和后台换曲仍由手机系统、浏览器决定，不能通过桌面浏览器的测试声称已完成手机锁屏验收。

程序入口、清单和播放器界面纳入 PWA 离线资源。歌曲文件按需通过浏览器加载，由原生播放器处理 HTTP Range 请求以支持拖动播放；本版不预下载或承诺歌曲离线可用。该模块没有答题计数、统计、每日任务或新的历史数据格式。

验证：基础测试检查整条平衡范围、独立样本与原幅度、立体声、补零、加载取消、音轨切换和资源释放。浏览器测试用独立生成的不同频率信号测量两轨输出，检查中点、两端及中间比例，以及单声道/立体声、暂停、拖动、循环和 320/390/900 像素排版。同时加载已提供的 WAV 检查混合及单独播放；不代表已人工试听或完成手机锁屏测试。

参考：[HTMLMediaElement.play](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play)、[原生循环](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/loop)、[Media Session](https://www.w3.org/TR/mediasession/)。
