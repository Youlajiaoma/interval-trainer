# 和声练唱音频接入

首页「练耳 → 和声练唱 → 在他乡」直接打开播放页，不再经过「旋律+和声／伴奏」选择页。当前使用用户提供的新版旋律、和声、吉他三份 WAV；点击歌曲后同步播放，返回歌曲目录立即停止。

文件放在 `site/assets/harmony-practice/zai-ta-xiang/`，清单在 `site/assets/harmony-songs.js`，例如：

```js
{
  id:'zai-ta-xiang', title:'在他乡',
  stems:{
    melody:'assets/harmony-practice/zai-ta-xiang/melody.wav?v=文件内容标识',
    harmony:'assets/harmony-practice/zai-ta-xiang/harmony.wav?v=文件内容标识',
    guitar:'assets/harmony-practice/zai-ta-xiang/guitar.wav?v=文件内容标识'
  },
  tracks:[
    {id:'ensemble', title:'在他乡', mix:['melody','harmony','guitar']}
  ]
}
```

`mix` 顺序为旋律、和声、吉他，也支持仅包含前两轨的歌曲。每首歌只有一个播放项目时直接打开播放器，仍兼容旧清单的多个音轨和独立录音写法。路径使用网页相对路径和正斜杠 `/`，不能填写电脑磁盘路径。替换音频后，将 URL 的 `v` 更新为新文件 SHA-256 的前 12 位，避免继续使用旧音频；资源检查核对内容标识和文件。文件按原样复制，不改音高、速度或音量。

平衡范围为 −100～100：0 对应旋律/和声增益 1/1；负值保持和声为 1，旋律为 `(100 + 值) / 100`；正值保持旋律为 1，和声为 `(100 − 值) / 100`。向左（旋律端）减少旋律，向右（和声端）减少和声；两端为 0/1 和 1/0。拖动不重新加载或改变播放位置；单轨页面不显示此控件。

平衡条前的 M 按钮点亮后，同时静音旋律和和声，吉他继续播放，进度继续前进。静音时调整平衡，这两轨仍然无声；取消 M 后恢复当前平衡值，不重播或跳转。

吉他控制行有独立 M 和 0～100% 线性音量条，默认 100% 原音量。M 点亮时吉他静音，调整滑块仍保持静音，取消 M 恢复当前设定值。两个 M 互不影响；调节音量不重载、不重播、不改变播放位置。

拖动进度时先暂停并临时静音全部三轨，连续拖动不播放任何位置片段。指针松开或键盘释放后，等最后一次跳转完成，再按原播放状态和各轨静音、音量设置恢复。原来暂停则保持暂停；临时静音不点亮任何 M。切换音轨或离开时取消等待，迟到的事件不会恢复声音。

歌曲清单联网时优先获取最新内容，离线时使用最近缓存的清单。首次更新旧网页后，可从本地预览的新地址打开并刷新；不需要清除练习记录或重新安装 PWA。仅修改本地文件不会同步到已发布网站。

新增歌曲时，在同一清单中追加一个有独立 `id`、`title` 和 `tracks` 的项目即可，目录自动生成。目录名称使用文本节点，音频通过相对路径引用。音频及其相关许可需由提供者确认。

当前播放器保留播放／暂停、进度、单次／循环播放，切换模式保留进度。只有一个播放项目时隐藏编号和上下音轨按钮，返回歌曲目录立即停止。多项目旧清单仍支持顺序播放、切换和逐级返回。歌曲目录、播放页和返回沿用已有界面动画。

所有项目复用同一个原生 HTML `audio`，以保留手机的播放许可。三份音频解码后，在内存中按独立声道封装进一个临时 WAV，共用一个媒体时钟，Web Audio 分别控制各轨增益并输出左右声道。三份单声道使用三个独立声道；有立体声时使用六个声道并保留每轨左右声道，较短音轨末尾补零。暂停、跳转和原生循环由同一时间轴控制。临时数据不预先叠加波形、不上传、不写入仓库，退出模块时释放。普通单轨仍直接输出。

切后台或锁屏时不主动暂停。支持时接入 Media Session 的锁屏播放/暂停、上下音轨及进度控制，并在播放期间请求 `audioSession.type = 'playback'`，离开后恢复。实际后台播放、Web Audio 处理和后台换曲仍由手机系统、浏览器决定，不能通过桌面浏览器的测试声称已完成手机锁屏验收。

程序入口、清单和播放器界面纳入 PWA 离线资源。三轨原始文件按需下载、解码，在临时媒体音源上跳转；普通单轨继续保留原生 HTTP Range 处理。本版不预下载或承诺歌曲离线可用。该模块没有答题计数、统计、每日任务或新的历史数据格式。

验证覆盖三轨独立样本、时长、单声道／立体声、双轨平衡、吉他全部整数音量、两个 M 互不影响、拖动时全轨静音、异步取消、目录返回和记录不变。浏览器在 320／390／900 像素下用不同频率信号测量实际输出，再加载三份实际 WAV 检查播放、进度及排版；不等同于人工试听和手机锁屏验收。

参考：[HTMLMediaElement.play](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play)、[原生循环](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/loop)、[Media Session](https://www.w3.org/TR/mediasession/)。
